# ❤️ Heart Disease Prediction

This project uses Machine Learning (Random Forest) to predict heart disease.

## 🚀 Features

* Trained model with optimized threshold
* ROC-AUC > 0.90
* Balanced performance

## 📊 Model Performance

* Accuracy: ~85%
* ROC-AUC: ~0.90

## 🧠 Tech Stack

* Python
* Scikit-learn
* Pandas
* NumPy

## ▶️ Run
uvicorn app:app --reload
python -m http.server 5500
